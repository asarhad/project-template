How to set this up (once)
  1. On GitHub, create a private repository — schengen-data is a good name. Leave it empty.
  2. Go to Settings → Developer settings → Personal access tokens → Fine-grained tokens and generate a new token.
  3. Under Repository access choose Only select repositories and pick that one repo. Under Permissions → Repository permissions set Contents to Read and write. Nothing else is needed.
  4. Give it an expiry date you're comfortable with, generate it, and copy the token.
  5. Paste the repository as owner/name and the token above, then press Connect & sync. Repeat only the paste step on each other device.

The token is stored in this browser and sent only to api.github.com. It can read and write that one repository and nothing else, and you can revoke it on GitHub at any time. Two devices editing at once are merged per trip — the most recent edit of each trip wins, and deletions are recorded so they don't come back.

The rules this applies

  1. 90 days maximum in any rolling 180-day period. Not "90 days per half-year" — the window moves with you, one day at a time.
  2. The window looks backwards. For any date, count the days you were inside Schengen on that date and the 179 days before it. Anything older has already dropped out, which is why your allowance grows again as time passes.
  3. Entry day and exit day each count as a full day, however briefly you were in the country. 28 Aug to 14 Sep is 18 days, not 17.
  4. All Schengen states share one 90-day budget. Greece, Spain, Italy, Croatia, Switzerland, Norway and the rest all draw on the same allowance. Ireland and Cyprus sit outside it.
  5. A trip is legal only if the limit holds on every day of it. Passing the test on your departure date is not enough — the figures here use the worst day.
  6. Days on a national long-stay (D) visa or a residence permit do not count toward the 90. Simply leave those out of the trips list.

Regulation (EU) 2016/399 — Schengen Borders Code, Article 6(1)(b)
